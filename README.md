# LuntikStore

**Центральный магазин приложений Luntik**

Скачивается и устанавливается **только через LuntikTerminal**.
После установки Terminal прячет свой ярлык — открыть его снова можно только из LuntikStore.

## Как получить

1. Установи **LuntikTerminal**
2. В терминале выполни:
   ```
   auth
   download
   verify
   install
   ```
3. LuntikStore установится, ярлык Terminal исчезнет

## Что будет внутри

- Список всех приложений Luntik
- Возможность скачивать обновления
- Кнопка / способ снова открыть LuntikTerminal
- Управление установленными приложениями

## Как скачать APK (для разработчиков)

1. **Actions** → последний успешный **Build APK**
2. Артефакт `luntikstore-debug-apk`

## Стек

- Kotlin + Jetpack Compose
- GitHub Actions (автосборка)
