# LuntikStore

**Центральный магазин приложений Luntik**

Скачивается и устанавливается **только через LuntikTerminal**.
После установки Terminal прячет свой ярлык — открыть его снова можно только из LuntikStore.

## Как получить

1. Установи **LuntikTerminal**
2. В терминале выполни:
   ```
   auth
   download
   verify
   install
   ```
3. LuntikStore установится, ярлык Terminal исчезнет

## Что будет внутри

- Список всех приложений Luntik
- Возможность скачивать обновления
- Кнопка / способ снова открыть LuntikTerminal
- Управление установленными приложениями

## Как скачать APK (для разработчиков)

1. **Actions** → последний успешный **Build APK**
2. Артефакт `luntikstore-debug-apk`

## Подпись APK и GitHub Secrets

Ключ подписи **больше не хранится в репозитории** (папка `keystore/` удалена и добавлена в `.gitignore`).
Автосборка берёт ключ из **GitHub Secrets** репозитория
(Settings → Secrets and variables → Actions → New repository secret):

| Секрет | Что это |
|---|---|
| `KEYSTORE_BASE64` | файл ключа (keystore), закодированный в base64 |
| `KEYSTORE_PASSWORD` | пароль хранилища ключей |
| `KEY_ALIAS` | имя (alias) ключа |
| `KEY_PASSWORD` | пароль ключа |

- Если секреты заданы — APK подписывается тем же ключом, что и раньше, проверяется отпечаток
  подписи и публикуется релиз `latest` (обновление ставится поверх установленного Store).
- Если секретов нет — APK собирается с обычным тестовым debug-ключом **только как артефакт**,
  релиз **не публикуется** (иначе обновление не встанет поверх установленного магазина).

⚠️ Старый ключ остаётся в истории git (коммит `5f2d95c`), поэтому его стоит считать публичным.
Удаление из последней версии не стирает его из истории.
